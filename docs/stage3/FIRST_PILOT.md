# Stage 3 — первый пробный запуск: выполнен PubMedBERT на 1 000 статьях

**Статус 11.11.2026:** первый **разрешённый бесплатный** P1 по PubMedBERT **ВЫПОЛНЕН**. Это вычислительный пилот, не завершение всего Stage3 и не разрешение полного корпуса. [07_STAGE_STATUS](https://docs.google.com/document/d/1GhQfnsbxK8lilvpnZqWeFu99w67DwWKJmY5OTthxvhM/edit) остаётся единственным источником Stage-gate статуса.

## Фактический результат

- **1 000 из 1 000** approved canonical journal articles получили две разные 768-мерные серии представления содержания — **CLS** и **masked mean**.
- Из них **883** статьи имели название + аннотацию и **117** — только название. Цельные записи выбраны по PubMed → WoS → APA; запрещённое соединение фрагментов разных источников не производилось.
- **74** длинные статьи потребовали разбиения текста, в сумме **1 075** проходов модели; **0** вынужденных разрезов предложений, **0** потерь токенов, title только в первом фрагменте. Два варианта вектора агрегированы с весами по содержательным токенам каждого фрагмента, затем отдельно сохранены сырые координаты, L2-нормы и единичные векторы.
- Фактический CPU расчёт: **183,4 секунды**, **5,45 статей/сек**, пик памяти процесса ~**999 MiB** (3 CPU threads, batch=4, torch 2.10.0+cpu, transformers 5.22.2). **Внешние расходы $0**.
- В закрытых выходах есть 1 000 исходных article ID, ссылка на выбранную source запись, статусы фрагментов и 10 примеров ближайших соседей для дальнейшей ручной содержательной оценки.

**Приватные результаты** хранятся только в restricted Google Drive project root как `STAGE3_P1_20261111_PUBMEDBERT_RESULTS_PRIVATE.zip`, **11 500 256 bytes**, SHA256 `5cb706e8b1fe9f210cd99cc4c2a10764447d500c9b742290917b314e75108844`. Внутри два варианта векторов по 1 000 × 768, отдельные L2-нормы, lineage, технический отчёт, запущенный исходный код и versioned manifest SHA256 `e1f147a99b5210bfd83d159841622cb2f0e32d0a3a320898da6fff6a15a402b4`. Сам корпус и векторы не публикуются на GitHub. ZIP защищён owner-only ACL/shared=false и после отдельного Google Drive скачивания повторно совпал побайтово, включая CRC и все internal file hashes.

## Какие исходные данные и модель использованы

- Принятая техническая выборка: 1 000 из 57 204 eligible canonical; 873 PubMed, 90 WoS, 37 APA; 252 структурных isolate. Исходный restricted input ZIP SHA256 `da92d16cfb2ac967f812aff2c219d8e6beaadd1175fd5f5bb401b4de53c716d8`.
- Frozen PubMedBERT: `microsoft/BiomedNLP-BiomedBERT-base-uncased-abstract`, full HF revision `d673b8835373c6fa116d6d8006b33d48734e305d`; реально полученные 440 474 434 bytes весов по SHA256 `d513412d396cecec5f67936ac871b4aaf1178dfb5193776e790fd2b28bba240c` совпали с поставщиком. Config/tokenizer/vocab SHA256 отдельно совпали с ранее сохранёнными байтами.
- Исполненный **offline CPU** код: [stage3_p1_pubmedbert_local.py](../../scripts/stage3_p1_pubmedbert_local.py). Внешние операции GitHub Actions использовались **только для открытых MIT-лицензированных файлов модели и библиотек**; закрытые title/abstract в GitHub Actions не попадали, а inference проходил только в локальной закрытой среде.

## Проверки и границы результата

(1) Независимая локальная проверка пересчитала содержимое всех выходных массивов: **100% ID/source lineage**, shape обеих линз 1 000 × 768, конечные ненулевые значения, нормы единичных векторов ≈1, исходная L2-норма соответствует raw vector, 1 075 фрагментов/74 длинные/117 title-only, отсутствие незаявленного усечения. (2) Раздельный Drive readback ZIP SHA256/CRC и пересчёт индивидуальных файлов дали точное совпадение. **Это техническая, не содержательная научная валидация.** Ближайших соседей предстоит посмотреть вручную.

**Что ещё не выполнено:** SPECTER2 proximity runtime остаётся заблокирован конфликтом опубликованных Adapters/Transformers; обучение node2vec не проводилось. Для полного вычисления на 57 204 статьях необходимо **отдельное решение владельца о compute, бюджете и переходе Stage**, прошедший P1 их не разрешает. Не требуется дополнительная цепочка preflight перед тем, как показать владельцу содержательный обзор первых полученных соседей.
