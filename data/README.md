# Scientific data is off-repository

Only this explanatory file is tracked. The actual scientific data layers under this directory are ignored by Git:

- `raw/`
- `normalized/`
- `canonical/`
- `derived/`

These ignored directories are execution caches only, not the permanent accepted artifact store. The private Google Drive project artifact package must be identified by explicit Drive ID, SHA-256 and verified readback; an owner-held USB copy remains separate. They are scientific/research storage, not public serving output.
